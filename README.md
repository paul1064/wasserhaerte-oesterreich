# Wasserhärte Österreich (MVP)
- Daten: `data/orte/<slug>.json` (eine Datei = eine Ortsseite). Nur offizielle Werte, mit `quelle` + `abgerufen`.
- Bauen: `python3 build.py` → `docs/` (GitHub Pages: Branch main, Ordner /docs).
- Amazon-Tag: Konstante `TAG` in build.py. Impressum: Platzhalter in build.py ersetzen. Sitemap: BENUTZERNAME/REPO in build.py ersetzen.
- Backlog: `backlog.csv`.
